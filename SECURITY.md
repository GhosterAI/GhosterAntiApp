# Security Policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability.

Email [security@ghosteranti.com](mailto:security@ghosteranti.com). Include the affected version, reproduction steps, and impact.

Never send real cookies, passwords, proxy credentials, TOTP seeds, profile exports, private keys, or unredacted diagnostics.

## Supported versions

GhosterAnti is currently in beta. Security fixes apply to the newest published release.

## Scope

Security reports may cover the desktop client, local API, installer, update notification, or interactions with GhosterAnti Cloud. The CloakBrowser runtime has its own security and reporting process.
